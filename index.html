📱 Getting Started

Before using the application, ensure your Android device is properly prepared:

  1. Enable Developer Options by tapping Build Number 7 times in Settings.
  2. Navigate to Developer Options and toggle it ON.
  3. Enable USB Debugging.
  4. Connect your phone to the PC via USB cable.
  5. When prompted on your phone, tap Allow USB Debugging (check "Always allow" for future sessions).
💡 Pro Tip: If connection fails, try disabling USB Debugging Security or enabling Disable Permission Monitoring in Developer Options.

🖥️ Interface Overview

The main window is divided into logical panels for quick navigation:

  • Top Bar: Displays your unique Hardware ID, connection status (ADB/COM), refresh controls, and theme toggle.
  • Left Panel: Package list with checkboxes, search bar, and color-coded legend. Right-click any app for quick actions.
  • Right Panel: Device information, progress tracking, and real-time operation logs.
  • Bottom Bar: Scrolling announcements & tips. Click to open the full Tips & Tricks dialog.

🧹 Managing Installed Apps

Use the main toolbar to perform bulk operations. Note: The Clean and Uninstall buttons target unchecked apps by default.

1. Clean & Uninstall

  • Clean (Unchecked): Clears app cache & storage data to free up space. Automatically includes Google Search, YouTube, and Chrome if detected.
  • Uninstall (Unchecked): Removes selected user apps. Ideal for removing pop-up adware or unused applications.

2. Exclusion Management

Protect important apps from accidental actions:

  • Select one or multiple packages.
  • Click ➕ Add to Excluded and choose Clean, Uninstall, or Both.
  • Excluded apps are automatically checked and color-coded. Right-click → Remove from Excluded to reverse.

3. App Backup & Icon Sync

  • 💾 Backup App APK: Right-click any app → Backup App APK. Saves single or split APKs to the backup folder.
  • ⚡ Show Icons: Fetches and displays app icons directly beside package names. Requires a one-time helper installation on the device.
  • 🔍 Identify Icon: Opens a popup to inspect an app's icon and search for it online.

⚙️ System App Disabler (Debloat)

⚠️ WARNING: Disabling or uninstalling system apps may cause bootloops, loss of functionality, or system instability. Proceed with caution.
  1. Click the ⚙️ Debloat button.
  2. Type YES in the verification prompt to proceed.
  3. The list switches to system apps: 📦 = Enabled, 🔐 = Disabled.
  4. Right-click or use the toolbar to:
    • Disable/Enable single or batch-checked apps.
    • Uninstall (prompts for APK backup first).

Disabled apps are automatically sorted to the top. Icons from previous syncs are preserved.

📦 APK Installation Mode

Install multiple APKs directly from a local folder:

  1. Click the folder icon or 📂 Install APKs button.
  2. Select the folder containing your .apk files.
  3. The list populates with available APKs. Check the ones you want to install.
  4. Right-click → Install This APK or click Install All Checked APKs.
  5. Click the folder icon again or use the back arrow to return to the device app list.

ℹ️ Activation Notes

  • Trial Mode: New users receive limited trial uses. The counter appears on first launch.
  • HWID Binding: Your activation is tied to your PC's unique Hardware ID (displayed in the top bar).
  • Offline Use: Once activated, the app works offline.
  • Re-activation: If you change major hardware components, contact support to reset your HWID.
💡 Before Contacting Support: Have your HWID ready (click 📋 to copy). Include your Windows version and Android device model for faster assistance.

❓ Troubleshooting & Tips

  • "No device detected": Ensure USB cable is data-capable, USB debugging is enabled, and the phone is unlocked. Try a different USB port.
  • "Cleaning failed" popup: Some Android skins block storage clearing. Enable Disable Permission Monitoring or disable USB Debugging Security.
  • Apps missing icons after sync: The helper requires ~10-30 seconds to export icons. Wait for the "DONE" confirmation before closing.
  • Batch operations stuck: Use 💀 Force Kill ADB, wait 2 seconds, then click 🔄 Refresh.
  • Closing the app: You will be prompted to disable Developer Options automatically for security (recommended for banking/GCash apps).
💡 Best Practice: Always backup important apps via the right-click menu before performing bulk uninstalls or system debloating.
